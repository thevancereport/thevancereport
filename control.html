Control room.

Change the website yourself: videos, Field Notes, the Author page, reviews, and the nightly jobs. Every change shows you exactly what will be different before it goes out, and every change can be undone.

Sign in with your GitHub key

Your site lives in GitHub, and Netlify publishes whatever is in GitHub about a minute later. A GitHub key lets this page save changes there for you. You make it once.

  1. Open GitHub → New fine-grained token (you're already signed in to GitHub in Chrome).
  2. Token name: Vance Report control room. Expiration: pick 1 year (or whatever you like; you'll just paste a new one when it runs out).
  3. Repository access: choose Only select repositories → thevancereport/thevancereport.
  4. Permissions → Repository permissions: set Contents to Read and write, and Actions to Read and write. Leave everything else alone.
  5. Click Generate token, copy it, and paste it below.
